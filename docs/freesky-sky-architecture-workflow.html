Freesky 三个 Sky 文件夹实现框架与工作流

本文基于 AgentSky、SprintbootSky、VueSky 当前代码整理。 每一段都附有可追溯的代码声明，并用 -> 表示模块、请求、状态之间的流动关系。

总览

AgentSky

Python FastAPI + LangGraph 多 Agent 小说创作运行时。它接收灵感文本，编排设定、人物、剧情、写作和审核。

SprintbootSky

Java 21 Spring Boot 业务后端。它负责认证、业务事务、调用 AgentSky、防腐转换、MySQL 持久化和 Redis 缓存。

VueSky

Vue 3 + Vite 创作台前端。它负责输入创作灵感、展示 Agent 日志、章节、人物、运行数据和响应式布局。

VueSky 创作台 -> SprintbootSky 业务 API -> AgentSky 多 Agent 工作流 -> SprintbootSky 落库/缓存 -> VueSky 展示结果

AgentSky 实现框架

AgentSky 的核心是一个共享状态对象和一个 LangGraph 图。所有 Agent 都围绕 AgentSkyState 读写字段， Supervisor 负责决定下一跳，专业 Agent 负责产出结构化 JSON。

AgentSky 工作流

AgentSky 的业务工作流由 Supervisor 决策驱动。蓝图未齐时补设定、人物、大纲；蓝图齐备后写正文； 正文必须经过 Reviewer，未通过时按问题类型回到对应 Agent 返工。

# AgentSky/graph/workflow.py
def supervisor_node(state: AgentSkyState) -> Command:
    result = _AGENTS["supervisor"].invoke(state)
    target = result.pop("next_action", "finish")
    goto = target if target in VALID_NODES else END
    return Command(goto=goto, update=result)

def reviewer_node(state: AgentSkyState) -> Command:
    result = _AGENTS["reviewer"].invoke(state)
    return Command(goto="supervisor", update=result)

SprintbootSky 实现框架

SprintbootSky 是三端之间的业务中枢。它不直接把 AgentSky 的原始响应暴露给前端，而是用 AgentSkyGateway 端口与 AgentSkyGatewayAdapter 防腐层把 HTTP、异常、JSON 和安全清洗隔离起来。

分层代码声明

# SprintbootSky/interfaces/novel/NovelController.java
@RestController
@RequestMapping("/api/novels")
public class NovelController {
    @PostMapping
    public ResponseEntity<CreateNovelResponse> createNovel(
            @Valid @RequestBody CreateNovelRequest request,

        NovelCreationResult result = novelApplicationService.createNovel(userId, request.idea());
        return ResponseEntity.status(result.success() ? HttpStatus.OK : HttpStatus.BAD_GATEWAY)
                .body(CreateNovelResponse.from(result));
    }
}

SprintbootSky 工作流

Spring Boot 创建小说时刻意拆成短事务。外部 LLM 创作可能耗时很长，因此调用 AgentSky 时不占用数据库事务和连接。 成功时整体落库，失败时写入安全错误并返回稳定业务响应。

VueSky 工作流

运行状态代码声明

# VueSky/src/composables/useNovelRun.ts
async function checkConnection() {
  const response = await fetch("/api/agent/health")
  const health: HealthResponse = await response.json()
  connected.value = health.status === "ok"
}

async function generate(idea: string) {
  status.value = "running"
  events.value = []
  result.value = null
  tokenUsage.value = null

  const response = await fetch("/api/novels", ...)
  const payload: GenerateResponse = await response.json()
  tokenUsage.value = payload.token_usage ?? null

  if (!response.ok || !payload.success) {
    throw new Error(payload.error || "创作失败，请稍后重试")
  }

  events.value = parseAgentLogs(payload.logs ?? [])
  result.value = normalizeNovelResult(payload.result)
  status.value = "completed"
}

三个 Sky 如何联通

三个项目通过 HTTP API 和稳定的数据协议联通。VueSky 在开发环境由 Vite 代理 /api 到 Spring Boot； SprintbootSky 用 RestClient 调 AgentSky；AgentSky 用 FastAPI 暴露创作与健康检查。

def create_novel(req: CreateRequest, service_token: str | None = Header(...)):
    expected_token = os.getenv("AGENTSKY_API_TOKEN", "").strip()
    if service_token is None or not secrets.compare_digest(service_token, expected_token):
        raise HTTPException(status_code=401, detail="Invalid AgentSky service token")

跨端数据协议

字段 AgentSky 产生 SprintbootSky 转换 VueSky 使用
logs server.py 捕获 stdout 与业务日志。 sanitizeLogs() 清洗敏感行；toRunLogs() 解析 agent 前缀落库。 parseAgentLogs() -> AgentTimeline。
result.completed_chapters SupervisorAgent._commit_reviewed_chapter() 写入已审核章节。 toChapters() 转成领域 Chapter 并写入 chapter 表。 ChapterReader 和已完成章节列表展示。
result.characters CharacterAgent 生成人物卡。 parseCharacters() 转成 CharacterProfile 并写入 character_profile。 normalizeCharacterCard() -> CharacterProfile.vue。
result.world_settings SettingAgent 生成设定库。 parseWorldSettings() 转成 WorldSetting，主表 JSON 保存。 ProjectNavigator 世界观目录展示。
result.plot_outline PlotAgent 生成章节大纲与伏笔。 parsePlotOutline() 转成 PlotOutlineItem，主表 JSON 保存。 ProjectNavigator 大纲目录展示。
token_usage TokenTracker.to_dict() 汇总调用次数、输入输出 token、费用、模型。 sanitizeTokenUsage() 保证非负数字和默认模型兜底，写入 token_usage 表。 RunInspector 展示 Token、费用、API 调用次数。

一句话总结

VueSky 是操作与展示层，SprintbootSky 是认证、事务、持久化和外部服务治理层， AgentSky 是真正执行小说生成的多 Agent 编排层。三者通过 /api 代理、 Spring Boot REST API、AgentSky FastAPI、JWT 和 X-AgentSky-Token 形成一条清晰边界的创作流水线。
