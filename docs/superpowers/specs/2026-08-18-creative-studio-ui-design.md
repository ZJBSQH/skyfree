# Freesky Creative Studio UI Design

## 目标

将当前单页生成表单升级为面向小说创作者的桌面工作台。界面以创作目录、Agent 工作过程和运行指标为核心，并为后续重点设计人物卡与接入 SSE 实时事件保留稳定的数据边界。

第一版继续使用现有同步接口 `POST /api/novels`。运行期间只展示能够确认的同步状态，完成后解析并展示 AgentSky 返回的真实日志；不使用定时器伪造 Agent 进度。

## 信息架构

### 左侧：创作目录

固定宽度约 260px，按小说项目组织：

- 概览：Agent 工作台
- 剧情：大纲与章节
- 角色：人物卡列表
- 设定：世界观条目
- 线索：伏笔库

每个分组显示真实数据数量。任务完成后，目录直接使用 AgentSky 返回的 `plot_outline`、`completed_chapters`、`characters` 和 `world_settings` 更新。空状态保留入口，但不展示虚构内容。

人物卡是产品后续的重点视觉对象。第一版提供清晰的基础结构：角色首字头像、姓名、角色类型、性格摘要、动机、能力与人物关系数量。点击人物条目后，中间区域切换到人物详情，为后续加入立绘、关系图和角色状态演化留出位置。

### 中间：创作与 Agent 工作区

中间列占据剩余空间，支持三种真实视图：

1. Agent 工作台：默认视图，显示任务时间线、当前运行状态和 Agent 日志。
2. 章节阅读：点击章节后展示完整审核正文。
3. 人物详情：点击人物后展示基础人物卡。

未开始时，Agent 工作台显示创意输入。提交后进入运行状态，禁用重复提交并显示已用时间。同步接口返回后，将 `logs` 中带 Agent 前缀的记录转换为时间线条目。错误时保留输入和错误信息，允许重试。

底部命令区包含创意输入、生成与重试操作。按钮使用 Lucide 图标；状态和命令使用明确文字，不使用装饰性胶囊按钮。

### 右侧：运行指标

固定宽度约 300px，展示：

- 服务链状态
- 当前任务状态
- 总 Token、输入 Token、输出 Token
- 模型调用次数与预估费用
- 执行时间
- 审核轮次
- 已完成章节数

所有指标来自 API 返回值或浏览器本地计时。未知指标显示 `--`，不推算虚假数据。右栏只用于扫描型数据，不嵌套卡片。

## 视觉系统

- 风格：安静、专业、偏编辑器工具，不采用营销页结构。
- 背景：浅中性灰；工作区使用白色和轻微边界建立层级。
- 功能色：绿色表示连接或通过，蓝色表示执行，琥珀色表示审核，红色表示错误。
- Agent：Supervisor、Setting、Character、Plot、Writer、Reviewer 使用固定 Lucide 图标和功能色，但不使用大面积单色主题。
- 圆角：控制在 6px，避免悬浮大卡片和卡片嵌套。
- 字体：系统字体，标题紧凑，正文适合长时间阅读；字距为 0。

## 响应式布局

- `>= 1180px`：完整三栏，左 260px、中间最少 520px、右 300px。
- `760px - 1179px`：右侧指标折叠为可切换抽屉，中间与左侧保留。
- `< 760px`：目录和指标均使用抽屉，中间内容占满屏幕；顶部提供图标按钮打开两侧面板。

固定栏使用稳定宽度和 `minmax(0, 1fr)`，保证长日志、中文正文和长角色名不会撑破布局。所有抽屉都有遮罩、关闭按钮和键盘可访问标签。

## 数据模型

前端维护统一的 `NovelRun` 状态：

- `status`: `idle | running | completed | failed`
- `startedAt`、`elapsedSeconds`
- `logs`: 解析后的 Agent 时间线
- `result`: AgentSky 返回的章节、人物、设定、大纲和审核数据
- `tokenUsage`: 输入、输出、总 Token、调用次数和费用

当前同步适配器负责将 `/api/novels` 响应转换成该模型。下一阶段 SSE 只替换数据输入方式：事件持续追加到相同的 `logs` 和指标字段，页面组件不需要重构。

## 组件边界

- `AppShell`：三栏布局和移动端面板状态。
- `ProjectNavigator`：创作目录与选择状态。
- `AgentWorkspace`：输入、任务状态和 Agent 时间线。
- `CharacterProfile`：人物卡基础详情。
- `ChapterReader`：章节正文。
- `RunInspector`：连接、Token、费用和执行指标。
- `useNovelRun`：API 请求、计时、响应转换和错误处理。

第一版允许这些组件保留在少量文件中，但职责和 Props 按以上边界定义，避免所有逻辑继续堆在 `App.vue`。

## 错误与安全

- 浏览器只访问 SprintbootSky，不接触 `AGENTSKY_API_TOKEN`。
- 同步请求失败时显示 Spring 返回的安全错误信息，不显示 Python traceback。
- 生成期间禁止重复提交；用户可以在错误后重试。
- 服务健康失败时生成按钮禁用，但目录中的既有结果仍可浏览。

## 测试与验收

- 单元测试覆盖目录切换、生成状态、日志转换、Token 指标和错误重试。
- 构建和 TypeScript 检查必须通过。
- 浏览器验证桌面、平板和手机断点，无横向溢出、文本遮挡或不可达操作。
- 真实联调只验证健康链路；自动 UI 测试使用模拟响应，避免消耗 DeepSeek Token。

## 后续阶段

1. 将 Spring 与 AgentSky 改为任务 ID + SSE 实时事件流。
2. 深化人物卡：角色立绘、关系图、状态演化、版本对比与一致性警告。
3. 增加章节编辑、局部重写和审核意见定位。
